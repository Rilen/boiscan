# Fixtures de fotografias reais

Conjunto pequeno e diversificado para testes de segmentação e inspeção visual.

- **Usáveis:** `holstein_1920s.jpg`, `bos_indicus_brazil.jpg`.
- **Difíceis:** `brahman_pasture.jpg` (vários animais), `beef_cattle_ayr_1989.jpg`
  (sombras e vários animais).
- **Inadequada para perfil:** `instituto_frontal.jpg` (animal de frente).

Cada entrada de `manifest.json` registra autoria, licença, URL de origem, ROI
normalizada, categoria e observações. Nenhum peso real é atribuído às imagens.

As imagens são miniaturas públicas do Wikimedia Commons, baixadas em 2026-11-03.
Créditos e licenças completos em [CREDITS.md](CREDITS.md).

Para revalidar as licenças, consulte as páginas de origem. Imagens CC BY exigem
atribuição em redistribuições.
